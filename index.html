DETERMINISTIC TESTING LAB / V0.6

Counterexample Machine

Test JavaScript against a reference or property using integers, arrays, strings, and JSON objects. Runs locally; no account or API required.

Tip: select Property-based testing, then replace the right editor with (actual, x) => actual >= 0 to test a rule without an oracle. Property checks should be independent of the candidate implementation.

Property mode: the right editor defines a function receiving (actualOutput, ...inputs) and returning true if the output obeys your rule. Random trials are deterministic for a given seed.

Structured input testing NEW

Each inner array contains the arguments for one function call. Example: [[[3,2,1]],[[1,2,3]]] tests a function accepting a single array. Custom cases are tested in order; shrinking is available only for generated integer tuples.

Implementation under test

Example: (x) => x > 0 ? x : -x + 1

Expected behavior (oracle)

The machine checks differences from this reference. A wrong oracle produces misleading findings.

Ready

Searches generated integer tuples or user-provided structured JSON cases. Stops at the first mismatch, then minimizes its arguments while preserving the failure. Each run has a 4-second timeout and a 60,000-case cap.
